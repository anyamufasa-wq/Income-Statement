# 利润统计原型

将此目录的全部内容上传到静态网站的发布目录，入口为 `index.html`。所有页面链接和资源使用相对路径，支持部署到子目录。

| 页面 | 文件 |
| --- | --- |
| 项目利润表 | profit-project.html |
| 部门利润报表 | profit-department.html |
| 客户利润报表 | profit-customer.html |
| 业务利润报表 | profit-business.html |
| 媒体利润报表 | profit-media.html |
| 媒体政策 | media-policy.html |

`assets/media-policy/xlsx.full.min.js` 为媒体政策 Excel 导入导出依赖，需一并上传。

媒体政策数据保存在浏览器本地存储中，不会上传到 Git 或在不同用户间共享。页面数据为原型演示数据。
